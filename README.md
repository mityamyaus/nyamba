# На неделю
Запуск: node server.cjs, http://127.0.0.1:4173.
Статический PWA-прототип. Данные рецептов и демонстрационные цены — dist/app.js. Каталоги и геопоиск не подключены. Сравниваются обычный и экономный шаблоны; калории масштабируют ингредиенты, стоимость учитывает упаковки. Настройки действуют до перезагрузки. Установка на телефоне не проверена.
