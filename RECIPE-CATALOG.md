# Русская кулинарная книга

Текущий источник коллекции — русский Викиучебник, категория «Рецепты». Импортировано 1404 страницы без установленного лимита. Это число страниц, а не гарантия 1404 полностью структурированных рецептов: есть описания блюд, варианты, соусы и справочные материалы. У 395 страниц распознан отдельный раздел приготовления. Остальной текст также сохранён для чтения.

База: data/wikibooks.sqlite. Офлайн-снимок: dist/wiki-recipes.json. Интерфейс: /recipes.html, ссылка из конструктора. API GET /api/recipes поддерживает q, cuisine=russian|european|asian и category=breakfast|lunch|dinner. Категории берутся из источника; отсутствие категории не означает, что блюдо не подходит. Часть кухонь пока не классифицирована.

Повторный импорт: python scripts/import-wikibooks.py. Используется публичный MediaWiki API, постраничный список категории и пакетное чтение редакций. Запросы последовательные с задержкой, кешируются в игнорируемой .sites-runtime/wiki-cache. Для получения свежих редакций предварительно очистите именно этот кеш. При ошибке выгрузки рабочая база не заменяется.

Тексты не пересказаны и не дополнены выдуманными инструкциями. Удалены изображения, вики-разметка, шаблоны оформления и справочный аппарат. Сохранены порядок разделов и варианты. Сложная или повреждённая вики-разметка требует дополнительной проверки. Хранятся ссылки на редакцию и историю авторов, дата, лицензия CC BY-SA 4.0. Условия указаны в каждой карточке.

КБЖУ, граммовки и порции не выдумываются. Новая коллекция пока не включена в автоматический планировщик: требуется сопоставление ингредиентов с продуктами, проверка количеств, аллергенов, техники и хранения. Старый планировщик и настройки пока сохранены. Удаление демо-рецептов, упрощение городов/магазинов и ориентировочные цены остаются следующей частью перехода.

Node 22.13+ / 24: чтение SQLite через node:sqlite. При обновлении базы требуется перезапуск приложения. Данные аккаунтов и кеш магазинов отдельно и не заменяются.

Обновление основного сценария: выбор города, магазинов и переход в отдельный каталог убраны из интерфейса. Первый шаг — кухни мира; фильтр действует на обеды и ужины текущего планировщика. Все суммы помечены ≈, закупки без названий сетей. Цены пока из базового справочника, а не подтверждённой выгрузки X5. Полный переход планировщика на импортированные рецепты ещё не выполнен.
